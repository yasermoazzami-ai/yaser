# تحلیل فنی و بنیادی از خروجی اکستنشن

۱. در اکستنشن روی «خروجی داده» بزنید، نمادها را وارد کنید و «شروع دریافت» را بزنید. فایل `tse-export-*.json.gz` دانلود می‌شود.
۲. گزارش را بسازید:

```
node analysis/tse-report.js tse-export-20260923-1200.json.gz --out report
```

خروجی‌ها در `report/`: `report.md` (گزارش فارسی)، `metrics.csv` (همه شاخص‌ها برای اکسل)، `metrics.json`.

گزینه‌ها: `--top 25` تعداد ردیف جدول رتبه‌بندی، `--cards 12` تعداد کارت تحلیل مفصل، `--min-value 3` حداقل میانگین ارزش معاملات ۲۰ روزه (میلیارد تومان) پیش از جریمه نقدشوندگی.

## چه چیزی محاسبه می‌شود
- قیمت‌ها برای افزایش سرمایه و سود نقدی تعدیل می‌شوند (از تفاوت «قیمت دیروز» با پایانی روز قبل).
- تکنیکال: MA20/50/200، RSI(14)، MACD(12,26,9)، ADX/DI، ATR، بولینگر، ایچیموکو، OBV، واگرایی RSI، حمایت/مقاومت فراکتالی و پیوت کلاسیک، قدرت نسبی به شاخص کل.
- تابلوخوانی: خالص حقیقی ۱/۵/۲۰ روز، نسبت آن به ارزش معاملات، قدرت خریدار، حقیقی قوی با فرمول SMT (`smart-money/smt-formula.js`).
- بنیادی: P/E با EPS پیش‌بینی یا TTM، مقایسه با P/E گروه، ارزش بازار، فهرست گزارش‌های کدال.
- امتیاز: ۳۰٪ روند، ۲۰٪ مومنتوم، ۲۵٪ جریان پول، ۲۵٪ ارزش؛ همراه با سیگنال، هشدارها و برنامه معامله (ورود، حد ضرر، هدف، R/R).

تست‌ها: `node --test analysis/tests/*.test.js`
