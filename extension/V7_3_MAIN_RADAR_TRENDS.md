# v7.3 — روند نمادها در رادار اصلی

در این نسخه همان روند نمادبه‌نماد v7.2 مستقیماً داخل کارت‌های رادار اصلی نمایش داده می‌شود.

بخش‌های رادار اصلی:
- ورود برآورد پول درشت
- خروج برآورد پول درشت
- ورود پول حقیقی
- خروج پول حقیقی
- آخرین قوی‌تر از پایانی
- آخرین ضعیف‌تر از پایانی

برای هر نماد سه روند نمایش داده می‌شود:
1. پول حقیقی
2. برآورد پول درشت
3. قدرت خرید

هر روند شامل مقدار فعلی، جهت روند، تغییر اخیر و نمودار کوچک است. روند فقط از داده معتبر جلسه اصلی بازار ساخته می‌شود؛ قبل از شروع بازار و روی Snapshot اول، روند ساختگی ایجاد نمی‌شود.
