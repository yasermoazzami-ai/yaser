TSETMC Stocks Radar v7.1 — Formula + Session Audited

هدف این نسخه: حفظ تجربه رادار قبلی، اما جدا کردن و بازنویسی منطق محاسباتی.

واحدها
- همه مبالغ داخلی: میلیارد ریال.
- تبدیل به تومان فقط در لایه نمایش انجام می‌شود: 10 میلیارد ریال = 1 میلیارد تومان.
- ضریب قدیمی MOJ3_TOMAN_UNIT_FIX=0.1 حذف منطقی شده و دیگر به‌عنوان «تبدیل واحد» داخل فرمول پول درشت اعمال نمی‌شود.

پول حقیقی
- اگر API تاریخی buy_I_Value / sell_I_Value داشته باشد، همان ارزش مستقیم استفاده می‌شود.
- در داده لحظه‌ای که ارزش مستقیم در bulk client-type موجود نیست، قیمت موثر = VWAP = ارزش معاملات / حجم معاملات.
- ورود/خروج حقیقی = ارزش خرید حقیقی - ارزش فروش حقیقی.

سرانه و قدرت
- سرانه خرید حقیقی = ارزش خرید حقیقی / تعداد خریدار حقیقی.
- سرانه فروش حقیقی = ارزش فروش حقیقی / تعداد فروشنده حقیقی.
- قدرت خرید = سرانه خرید / سرانه فروش؛ قدرت فروش معکوس آن است.
- aliasهای تاریخی buy_I_Count و sell_I_Count نیز پشتیبانی می‌شوند.

برآورد پول درشت
TSETMC در داده تجمیعی ClientType، برچسب «معامله درشت» برای تک‌تک معاملات نمی‌دهد. بنابراین مقدار دقیق پول درشت از این داده‌ها قابل استخراج نیست.
این نسخه آن را صریحاً «برآورد پول درشت» می‌نامد و از یک برآورد bounded استفاده می‌کند:
1) سهم درشت بر اساس سرانه از 50 میلیون تومان شروع می‌شود.
2) تا حدود 600 میلیون تومان با تابع smoothstep به 100% نزدیک می‌شود.
3) قدرت خریدار/فروشنده فقط یک tilt محدود 0.85 تا 1.15 ایجاد می‌کند.
4) برآورد خرید/فروش درشت هرگز از کل ارزش خرید/فروش حقیقی بیشتر نمی‌شود.

هشدار لحظه‌ای
- به‌جای تفاضل دو مقدار تجمعیِ دوباره‌ارزش‌گذاری‌شده، دلتا از تغییر حجم حقیقی بین دو snapshot محاسبه می‌شود.
- اگر شمارنده تجمعی reset/reconcile شود و دلتا منفی باشد، هشدار سرکوب می‌شود.
- آستانه 2 میلیارد تومان = 20 میلیارد ریال داخلی.

۳/۵ روزه
- تاریخچه ClientType از valueهای مستقیم حقیقی استفاده می‌کند، نه حجم × close وقتی value موجود است.
- 3 روزه فقط با 3 روز معاملاتی معتبر و متمایز؛ 5 روزه فقط با 5 روز معتبر و متمایز نمایش داده می‌شود.

میانگین ۵/۲۰ روزه
- MA5 تا قبل از داشتن 5 روز کامل مقدار ندارد.
- MA20 تا قبل از داشتن 20 روز کامل مقدار ندارد.
